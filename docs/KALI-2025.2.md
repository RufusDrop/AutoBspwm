# AutoBspwm en Kali Linux 2025.2 (VMware)

Ejecuta el instalador con tu usuario normal desde el directorio del repositorio:

```bash
chmod +x AutoInstall.sh install.sh theme.sh
./AutoInstall.sh
```

El instalador usa los paquetes de Kali para `bspwm`, `polybar` y `picom`; no
ejecuta `apt upgrade`. Powerlevel10k se instala en una versión fijada y dentro
de `~/.local/share/autobspwm`, nunca en el Zsh predeterminado. Selecciona
**Matterhorn** para la variante azul basada en ZLCube o **Nord** para la paleta
Nord canónica. Al terminar, cierra la sesión y elige **AutoBspwm** en LightDM.

## Instalación segura y conservación del historial

Antes de instalar, crea una instantánea de la máquina virtual en VMware. Abre
una terminal **zsh** y fuerza el guardado de los comandos de la sesión actual:

```zsh
fc -W ~/.zsh_history
```

Después guarda una copia de la configuración y del historial. El bloque admite
que algunos de los archivos no existan todavía:

```bash
backup="$HOME/autobspwm-preinstall-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$backup"
for file in .zshrc .zsh_history .p10k.zsh; do
  [ -e "$HOME/$file" ] && cp -a -- "$HOME/$file" "$backup/"
done
printf 'Copia creada en: %s\n' "$backup"
```

Clona o copia este fork, entra en su directorio y ejecútalo **sin `sudo`**:

```bash
git clone <URL-DE-TU-FORK> AutoBspwm
cd AutoBspwm
chmod +x AutoInstall.sh install.sh theme.sh
./AutoInstall.sh
```

El script pedirá la contraseña únicamente cuando APT y el registro de la sesión
lo necesiten. Antes crea automáticamente otra copia preventiva en
`~/autobspwm-preinstall-<fecha-hora>/`. Muestra un único selector Rofi llamado
**Perfil AutoBspwm**. Elegir `Nord` en esa lista instala el perfil completo; no
es el selector global `rofi-theme-selector`. No borres ni restaures
`.zsh_history` durante el proceso: el instalador solo la copia.

El antiguo segundo selector solo cambiaba la apariencia del lanzador Rofi; no
configuraba ventanas, BSPWM, Picom ni Polybar. Este fork no lo abre porque cada
perfil ya instala un `config.rasi` privado con colores coordinados y el selector
global podía sobrescribirlo o aplicar temas incompatibles con Rofi 2.

Tras seleccionar un perfil, cierra sesión. Para usarlo, selecciona
**AutoBspwm**; para volver al escritorio normal, selecciona la sesión
predeterminada de Kali. No uses la entrada genérica **BSPWM**, porque no carga
el contenedor aislado del perfil.

## Alternar con la sesión predeterminada de Kali

El instalador no reemplaza `.zshrc`, `.p10k.zsh`, Kitty ni Fastfetch. Cada
perfil se guarda bajo `~/.config/autobspwm/profiles/` y la sesión
**AutoBspwm** le asigna su propio `XDG_CONFIG_HOME` y `ZDOTDIR`. Por tanto, al
seleccionar la sesión habitual de Kali no se inicia ni se lee la configuración
de BSPWM, Polybar, Picom, Kitty o Powerlevel10k del perfil.

Dentro de AutoBspwm, el Zsh privado carga primero tu `.zshrc` normal para
conservar completado e historial, restaura los alias con iconos y colores del
proyecto original mediante `lsd` (`ls`, `ll`, `la` y `lla`) y después aplica
el Powerlevel10k privado. `HISTFILE` continúa apuntando a `~/.zsh_history`.

Si instalaste antes el script original de 2023, este sí podía haber sustituido
`.zshrc` e instalado Powerlevel10k. No borres esos archivos a ciegas: restaura
tu copia anterior de `.zshrc` si la conservas. Las nuevas ejecuciones de este
fork ya no los modifican.

## Teclado español de España

La primera aplicación de un tema crea `~/.config/autobspwm/local.sh` con:

```sh
setxkbmap -layout es -variant '' -option ''
```

Ese archivo no se reemplaza al cambiar de perfil y BSPWM lo carga en cada
inicio. Si prefieres otra variante, edita únicamente esa línea.

## Copias de seguridad y retorno

Antes de reemplazar un perfil ya instalado se guarda una copia en
`~/.config/autobspwm-backups/<fecha-hora>/`. Los directorios personales de Kali
no se eliminan. Para volver a un perfil, ejecuta:

```bash
./theme.sh ZLCube
```

También puedes ejecutar `./theme.sh` sin argumento para abrir de nuevo el único
selector de perfiles. El cambio queda activo en el siguiente inicio de
AutoBspwm; no afecta a la sesión predeterminada de Kali.

## Diagnóstico

Los procesos de fondo ya no descartan sus errores. Si algo no aparece, revisa:

```bash
cat ~/.cache/autobspwm/polybar.log
cat ~/.cache/autobspwm/picom.log
cat ~/.cache/autobspwm/powermenu.log
```

La configuración de Picom evita las opciones retiradas que provocaban el
diálogo `picom Warning`, y Polybar usa rutas absolutas compatibles con 3.7.x.
El instalador tampoco ejecuta `rofi -rasi-validate`: la versión 2.0.0-0.2 de
Kali puede terminar con un fallo de segmentación en ese modo de validación.

## VMware

Se instala `open-vm-tools-desktop`, que es el conjunto de herramientas de
VMware recomendado por Kali. Los perfiles aplicados reemplazan la llamada
obsoleta a `vmware-user-suid-wrapper` por `vmware-user` si está disponible.
