# AutoBspwm en Kali Linux 2025.2 (VMware)

Ejecuta el instalador con tu usuario normal desde el directorio del repositorio:

```bash
chmod +x AutoInstall.sh install.sh theme.sh
./AutoInstall.sh
```

El instalador usa los paquetes de Kali para `bspwm`, `polybar` y `picom`; no
compila ramas cambiantes desde Git ni ejecuta `apt upgrade`. Selecciona
**Matterhorn** para la variante azul basada en ZLCube o **Nord** para la paleta
Nord canónica. Al terminar, cierra la sesión y elige **BSPWM** en LightDM.

## Instalación segura y conservación del historial

Antes de instalar, crea una instantánea de la máquina virtual en VMware. Abre
una terminal **zsh** y fuerza el guardado de los comandos de la sesión actual:

```zsh
fc -W ~/.zsh_history
```

Después guarda una copia de la configuración y del historial. El bloque admite
que algunos de los archivos no existan todavía:

```bash
backup="$HOME/autobspwm-preinstall-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$backup"
for file in .zshrc .zsh_history .p10k.zsh; do
  [ -e "$HOME/$file" ] && cp -a -- "$HOME/$file" "$backup/"
done
printf 'Copia creada en: %s\n' "$backup"
```

Clona o copia este fork, entra en su directorio y ejecútalo **sin `sudo`**:

```bash
git clone <URL-DE-TU-FORK> AutoBspwm
cd AutoBspwm
chmod +x AutoInstall.sh install.sh theme.sh
./AutoInstall.sh
```

El script pedirá la contraseña únicamente cuando APT la necesite. Instala las
dependencias empaquetadas por Kali, muestra el selector y conserva una copia de
la configuración de BSPWM que ya existiera antes de sustituirla. No borres ni
restaures `.zsh_history` durante este proceso: el instalador actual no lo lee ni
lo modifica.

Tras seleccionar un perfil, cierra sesión. Para usarlo, selecciona **BSPWM**;
para volver al escritorio normal, selecciona la sesión predeterminada de Kali.
No hace falta desinstalar nada entre ambos modos.

## Alternar con la sesión predeterminada de Kali

El instalador no reemplaza `.zshrc`, `.p10k.zsh`, Kitty ni Fastfetch. Los
perfiles solo copian configuración de BSPWM, Polybar, Picom, sus scripts y sus
fondos dentro de `~/.config/`. Por tanto, al seleccionar la sesión habitual de
Kali en LightDM no se inicia BSPWM, Polybar ni Picom, y el terminal conserva el
prompt que tuviera antes de usar este fork.

Si instalaste antes el script original de 2023, este sí podía haber sustituido
`.zshrc` e instalado Powerlevel10k. No borres esos archivos a ciegas: restaura
tu copia anterior de `.zshrc` si la conservas. Las nuevas ejecuciones de este
fork ya no los modifican.

## Teclado español de España

La primera aplicación de un tema crea `~/.config/autobspwm/local.sh` con:

```sh
setxkbmap -layout es -variant '' -option ''
```

Ese archivo no se reemplaza al cambiar de perfil y BSPWM lo carga en cada
inicio. Si prefieres otra variante, edita únicamente esa línea.

## Copias de seguridad y retorno

Antes de cambiar un perfil se guardan los directorios gestionados en
`~/.config/autobspwm-backups/<fecha-hora>/`. Los directorios personales que no
gestiona AutoBspwm no se eliminan. Para volver a un perfil, ejecuta:

```bash
./theme.sh ZLCube
```

## VMware

Se instala `open-vm-tools-desktop`, que es el conjunto de herramientas de
VMware recomendado por Kali. Los perfiles aplicados reemplazan la llamada
obsoleta a `vmware-user-suid-wrapper` por `vmware-user` si está disponible.
